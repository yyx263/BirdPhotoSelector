# RAW 支持：第四至六步实现记录

记录日期：2026-10-30。第 4 步文件处理与第 5 步单张重建已完成，最终回归集中在第 6 步；版本更新为 1.7.0。此记录描述本地完成的程序与发布包，不表示已提交、推送或创建线上 Release。

## 文件范围和逐成员结果

导出对话框的评级范围保持独立，文件范围单选全部、仅 JPG 或仅 RAW，默认全部。显示匹配的逻辑照片数、已管理文件数；没有匹配成员不能开始，导出目标必须是现有目录。

主窗口在确认前生成不可变的成员计划，包含成员身份、固定完整路径及可读取的文件状态；执行期间不发现新的同名文件，也不逐张解码 RAW。进度同时显示照片和文件序号及当前路径，结果按成员记录复制、验证、移除、跳过、失败和取消。

导出使用 CreateNew，保留原始字节，大小与 SHA-256 一致才标为验证成功。选择导出后移除时，同一照片的全部所选成员均复制验证成功后，重新打开并验证所有目标副本，持有其只读锁直至该张移除完成；任一目标缺失或改变则整张原件保留。移除前重新验证源文件状态与内容。任一成员复制冲突、失败或取消时不开始该张原件移除；已经验证的目标副本可以保留，并报告未完成原因。

直接删除及移除阶段允许部分成功，取消不会回滚已完成的文件操作。只在 UI 线程把确实移除的成员从原照片去掉；所有成员均无剩余后才移出整张记录。原件外部缺失时报告跳过，保留成员审计，不冒充程序删除成功。使用回收站失败时不会自动重试永久删除；不支持回收站的磁盘仍沿用系统行为并在确认中说明。

只移除 JPG 后仍有 RAW，保留照片 ID、评级、分组、鸟种、编号和历史几何参考。活动来源切换到 RAW、旧框待核对，只有当前浏览照片按需加载 RAW；其他照片不会在批量删除里等待解码。未验证旧坐标不参与叠框、视图、裁切或背景排除。

## 重新识别本张

按钮位于鸟种结果区域。首次确认明确成功后替换该张全部自动框、手动选区和原鸟种结果；评级、分组及其他照片保留。

服务在调用线程快照原对象、选择、编号、视图、成员和状态，后台从当前来源重新解码、定位并识别全部新框，失败或任意阶段取消均不改旧状态。新框全部识别成功才返回完整候选；原片状态和 SHA-256 在识别前后、提交前验证，原对象或来源改变则拒绝过期结果。正常零检出需要 UI 第二次确认后才允许清空，拒绝时保留旧结果。

成功提交替换全部旧自动/手动框，以原 NextBirdNumber 继续编号，选中面积最大的鸟，建立当前来源的有效几何参考并清除旧视图。待核对照片可使用该动作，普通批量识别继续保留手动框，并跳过待核对旧坐标。

## 发布与边界

完整发布目录为 `publish/BirdPhotoSelector`，包含 .NET Windows Desktop 运行库、YOLO、BioCLIP 2、RAW 桥接、LibRaw、三个实际 C++ 运行库依赖、许可和说明文件。开发者需 MSVC 编译工具，使用完整包的用户无需安装 Visual Studio 或 .NET。

工程保存为 v2，旧版 1.6.1 不能打开。真实 RAW 验证只证明实测机型和模式，尚无全部品牌覆盖保证；HE 反例明确不支持。真实竖拍 RAW、更多裁切模式及同拍相机 JPG 的几何映射仍需后续样片，切源默认待核对并提供显式重建。

本地 ZIP 为 `publish/BirdPhotoSelector-1.7.0-win-x64.zip`，SHA-256 旁置文件与其同名加 `.sha256`；程序目录内 `release-manifest.json` 记录逐文件大小及哈希。发布验证记录为 `artifacts/release-1.7-package-validation.json`。源码不包含模型缓存、测试样片或大压缩包。线上提交、标签及 GitHub Release 由后续明确操作处理，不自动上传 Gitea 资产。
